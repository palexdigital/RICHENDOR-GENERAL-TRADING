# Richendor General Trading Store

A simple static e-commerce website for an Apple products store.

## Files

- `index.html` - page content, sections, cart drawer, product and checkout dialogs.
- `css/variables.css` - design tokens copied into editable CSS variables.
- `css/styles.css` - layout, product cards, cart, checkout, and responsive styles.
- `js/app.js` - product data, filters, cart, local storage, and demo checkout.
- `images/` - editable SVG product images.

## Editing Products

Open `js/app.js` and edit the `products` array. Each product has:

- `id`
- `name`
- `category`
- `price`
- `image`
- `description`
- `colors`
- `specs`

## Publishing On GitHub Pages

Upload this folder to a GitHub repository. In the repository settings, enable GitHub Pages and choose the branch containing `index.html`.
